# Введение

Проект предназначен для расчета индекса массы тела пользователя на основе его роста и веса.
Сервис позволяет определить категорию массы тела и получить рекомендации.

# Примеры использования

1. При вводе роста система сохраняет значение.
2. При вводе веса система сохраняет значение.
3. При нажатии кнопки «Рассчитать» вычисляется ИМТ.
4. При нажатии кнопки «Очистить» поля очищаются.
5. При неверном вводе отображается сообщение об ошибке.
6. При вводе роста в сантиметрах выполняется автоматическое преобразование.
7. При расчете отображается значение ИМТ.
8. При расчете определяется категория веса.
9. При нажатии кнопки «Сохранить» результат записывается в историю.
10. При открытии истории отображаются предыдущие расчеты.
